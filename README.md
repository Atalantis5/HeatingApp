# 重力循环双管热水供暖管网水力计算系统

> **产品说明书（V7.2 · 生产单端口部署版）**
>
> 一套面向暖通设计人员的桌面级 Web 工具：在浏览器里拖拽绘制管网拓扑，系统自动用**图论寻优**
> 找出最不利环路与并联环路共用管段，再用教材同源的**插值选径 + 水力计算公式**完成选径、阻力计算
> 与平衡校核，最后生成决策看板与 Markdown / Excel 报表。所有案例数据保存在本地 SQLite，无需联网、
> 无需数据库服务器。

## 1. 项目介绍

本系统以《供热工程》重力循环双管热水供暖系统教材案例为基准，把传统“手工查表 + 手算环路”的流程
升级为“**拖拽建图 → 自动寻优 → 自动选径 → 自动平衡校核 → 报表输出**”的完整工具链：

- **图论寻优（NetworkX）**：自动识别热源/末端，枚举全部“热源→末端”水流路径，按总长度自动选出
  最不利环路 Loop1；其余路径自动求与 Loop1 的交集/差集，得到各并联环路的共用管段与独用管段。
- **插值选径（data_loader）**：基于《热水采暖管道水力计算表》插值得到流速 v、比摩阻 Rm，按平均
  比摩阻就近选择标准管径（DN15～DN100）。
- **物理计算（engine，冻结）**：沿程阻力、局部阻力、动压头、总阻力、作用压力、不平衡率等全部
  由后端统一计算，前端不包含任何水力公式。
- **产品化能力**：可拖拽拓扑编辑器、拓扑自检与自然语言报错、Dagre 一键排版、结果决策看板、
  Markdown/Excel 报表、SQLite 案例持久化、单端口生产部署。

**适用场景**：单热源、异程式枝状管网的重力循环双管热水供暖系统方案初算、教学演示与快速复核。

## 2. 核心功能

| 功能 | 说明 |
| --- | --- |
| 🧩 **拖拽建图** | 从节点面板拖入「锅炉 / 散热器 / 立管节点」，在画布上连线即自动生成管段（Q/l/Σξ 初始为 0，管径默认“自动”） |
| 🛡️ **拓扑自检** | 点击计算/校验前，浏览器先检查：唯一锅炉、无孤立节点、无断头路、无环状管网、整体连通；后端再次防御并返回中文错误 |
| 📐 **一键排版** | 基于 Dagre 的 TB 分层排版，把散乱的画布节点整理成整齐的上下分层结构，不改变连接关系与管段数据 |
| 🧠 **自动寻优** | 自动识别最不利环路 Loop1 与所有并联环路，自动扣除共用管段阻力，计算独用资用压力与不平衡率 |
| 📊 **结果决策看板** | 系统富裕度（≥10% 绿色 / <10% 红色）、最不利环路总阻力、作用压力；各并联环路不平衡率进度条（>15% 红色）；warnings 异常诊断日志 |
| 📄 **报表导出** | 一键复制 Markdown 报表；导出 Excel（含计算摘要、最不利环路管段、并联环路汇总/明细、拓扑解析、异常诊断多个工作表） |
| 🗄️ **案例持久化** | 案例（名称 + nodes/edges/segments + 计算结果）保存到本地 SQLite `projects.db`，支持新建、加载、保存、克隆、删除；刷新/重启不丢失 |
| 🖥️ **单端口部署** | 生产模式下 FastAPI 同时托管前端 `dist` 与 API（端口 8000），一个窗口、一个地址即可使用 |

## 3. 两种启动模式

> **环境要求**：Windows 10/11；Python 3.12+；Node.js 18+（仅开发/重新构建前端时需要）。
> 首次使用请先完成 [第 5 节](#5-首次安装与构建) 的依赖安装。

### 3.1 普通用户模式（推荐）：`start_prod.bat`

**双击 `start_prod.bat`**，脚本会：

1. 检查 `.venv` 虚拟环境、`uvicorn`、`dist/index.html` 是否存在；
2. 激活 `.venv`；
3. 启动单端口服务：`uvicorn main:app --host 127.0.0.1 --port 8000`；
4. 服务就绪后**自动打开默认浏览器**访问 <http://127.0.0.1:8000>；
5. 关闭服务或报错时窗口会 `pause` 停留，不会一闪而过。

**特点**：单窗口、单端口；前端静态资源、API、SQLite 数据库全部走 `127.0.0.1:8000`；
无需启动 Node/Vite；适合日常使用与交付演示。

### 3.2 开发者模式：`start_dev.bat`

**双击 `start_dev.bat`**，脚本会打开两个 CMD 窗口：

| 窗口 | 作用 | 地址 |
| --- | --- | --- |
| 后端 | 激活 `.venv`，运行 `uvicorn main:app --reload` | <http://127.0.0.1:8000> |
| 前端 | 运行 `npm run dev`（Vite 热更新） | <http://127.0.0.1:5173> |

浏览器自动打开 <http://127.0.0.1:5173>；Vite 将 `/api/*` 代理到后端并去掉前缀，
因此开发时也只需访问 5173。修改前端源码会即时热更新，适合二次开发与调试。

> 若需要“开发者模式但浏览器不自动打开”，可先设置环境变量 `START_DEV_SKIP_BROWSER=1`；
> 生产模式同理使用 `START_PROD_SKIP_BROWSER=1`（用于自动化/无界面环境）。

## 5. 首次安装与构建

在 `05_engine/04_ProgramFile` 目录打开 CMD/PowerShell：

```bat
REM 1) 创建并安装 Python 虚拟环境（首次）
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

REM 2) 安装前端依赖并构建生产包（首次/前端改动后）
npm install
npm run build

REM 3) 启动普通用户生产模式
start_prod.bat
```

> `dist/` 与 `projects.db` 会在构建/首次启动时自动生成。生产模式**不需要 Node** 持续运行，
> 只依赖已构建好的 `dist`。

## 6. 使用指南

1. **新建/加载案例**：左侧「案例管理」可新建案例、保存、加载、克隆、删除；所有操作均为后端 HTTP 请求，
   数据写入 `projects.db`。
2. **绘制拓扑**：从节点面板拖入锅炉（必需且唯一）、立管节点/散热器，在节点锚点之间拖拽连线；
   连线成功会自动生成一条管段。
3. **一键排版**：点击画布上方「一键自动排版」，Dagre 会按 TB 方向整理节点位置；连接关系与管段参数不变。
4. **填写管段参数**：在右侧「管段参数」表填写 Q（热负荷 W）、l（长度 m）、Σξ（局部阻力系数）；
   管径可选「自动」或锁定 DN15～DN100。
5. **拓扑自检**：点击「提交校验」或「开始计算」前，前端会先做图论校验；若有断头路、环状管网、
   多热源、孤立节点等，会弹出红色自然语言提示并中止请求，同时在画布上方显示错误清单。
6. **开始计算**：后端自动运行 Part A（最不利环路选径/迭代）与 Part B（并联环路平衡）；
   结果显示在「结果决策看板」。
7. **导出报表**：结果区上方「复制为 Markdown」一键复制报表；「导出 Excel」下载
   `[案例名]_水力计算表.xlsx`（多工作表）。
8. **保存成果**：点击左侧「保存当前案例」把当前拓扑、参数、计算结果写回 SQLite；刷新或重启后自动恢复。

## 7. 数据存放与备份

- 数据库文件：`05_engine/04_ProgramFile/projects.db`（SQLite，单文件）。
- 首次启动且数据库为空时，自动写入**教科书默认案例（图4-3-1）**：21 个节点 / 25 条边 / 25 个管段，
  管段 Q/l/Σξ 完全来自 `02 Calculation Sheet/默认管路模型_管段明细参数.xlsx`。
- **备份**：停止服务后直接复制 `projects.db` 即可。
- **恢复**：停止服务，用备份文件覆盖 `projects.db`，重新启动。
- **重置**：停止服务，删除 `projects.db`，下次启动会自动重建表结构并重新写入默认案例。
- `02 Calculation Sheet/` 为只读数据源，系统只在运行时读取，不会写入或改动原始 Excel。

## 8. 后端 API 一览

单端口模式下 API 同时支持直接路径与 `/api` 前缀（前端统一使用 `/api`，由兼容层内部重写）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/projects` | 案例列表（仅 id / name / updated_at） |
| GET | `/projects/{id}` | 案例完整数据（nodes / edges / segments） |
| POST | `/projects` | 新建案例（UUID 主键） |
| PUT | `/projects/{id}` | 更新案例（覆盖 data） |
| DELETE | `/projects/{id}` | 删除案例 |
| POST | `/validate-topology` | 拓扑校验（图模式：DAG/单热源/末端） |
| POST | `/calculate` | 水力计算（Part A + Part B + 自动寻优结果） |
| POST | `/export/markdown` | Markdown 报表（纯文本） |
| POST | `/export/excel` | Excel 报表文件流 |
| GET | `/docs` | Swagger API 文档 |

## 9. 计算口径与已知限制

- **物理口径**：全部由冻结的 `engine.py` / `data_loader.py` 计算；管径选择采用水力计算表插值 +
  比摩阻就近选径；教材默认案例复算误差 ≤ ±2%（详见自动化测试）。
- **Part B 判据**：并联环路不平衡率限值 ±15%；超出时给出建议，不自动缩径；DN15 为硬性缩径底线。
- **拓扑限制**：当前仅支持**单热源、枝状有向无环管网**；环状管网、多热源会被前后端拦截并给出中文提示。
- **说明**：默认模型将回水汇合节点表达为 `merge` 节点，属于枝状管网正常结构，不是环状管网。

## 10. 常见问题排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 双击 `start_prod.bat` 窗口一闪而过 | 缺少 `.venv` / `uvicorn` / `dist` | 按提示先执行第 5 节安装与构建；脚本末尾有 `pause`，可查看具体报错 |
| 浏览器打开 8000 显示 JSON 404 | 访问了不存在的 `/api` 路径 | 请访问 <http://127.0.0.1:8000/>；未知 API 返回 JSON 404 属正常保护 |
| 页面空白 / 刷新 404 | 缺少 `dist` 或构建失败 | 执行 `npm run build` 重新生成 `dist` |
| 端口 8000 被占用 | 已有服务在运行 | 关闭占用进程，或修改 `start_prod.bat` 中 `--port` 参数 |
| 前端请求报跨域 | 直接打开 5173 但后端未启动 | 使用 `start_dev.bat` 同时启动前后端；生产模式统一走 8000 无跨域 |
| 数据库损坏/想重置 | 手工改库或异常断电 | 停止服务 → 备份/删除 `projects.db` → 重启自动重建默认案例 |
| 想修改数据源 Excel | 系统只读 `02 Calculation Sheet` | 不直接改原始 Excel；如需新模型请另建案例绘制拓扑 |
